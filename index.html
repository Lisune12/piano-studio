Votre instrument

Mode démo · aucun accès MIDI demandé.

Sur Chrome Android : ouvrez ce site en HTTPS, branchez un clavier MIDI compatible via USB/OTG, puis autorisez l’accès avec le bouton. Le tactile reste toujours disponible.

Besoin d’un coup de main ?

Allumez votre clavier et vérifiez le câble/adaptateur USB. Si l’accès est refusé, autorisez MIDI dans les paramètres du site puis réessayez. Si aucun appareil n’apparaît, rebranchez-le. La compatibilité dépend du téléphone et du clavier.
